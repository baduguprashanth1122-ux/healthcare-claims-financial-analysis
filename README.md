# Healthcare Claims Cost Driver & Financial Analysis

## 📌 Project Overview
This project analyzes commercial healthcare claims data to diagnose inpatient vs. outpatient cost drivers, evaluate reimbursement variances, and uncover spending concentration. 

## 📂 Repository Structure
- `sql/` - Contains the clean MySQL script used for data cleaning, aggregations, and calculating paid-to-billed ratios.
- `dashboard/` - Contains a high-resolution preview of the Power BI executive dashboard.
